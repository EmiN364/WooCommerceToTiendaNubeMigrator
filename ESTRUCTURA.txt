│

📦 ARCHIVOS A CREAR POR TI
---------------------------

├── 🔐 .env                      ← Tu configuración (copiar desde config.example.env)
└── 📁 exports/                  ← Generado por export-data.js
    ├── categories.json          ← Backup de categorías
    ├── products.json            ← Backup de productos
    └── report.json              ← Reporte de análisis

====================================================
  COMANDOS DISPONIBLES
====================================================

npm install          → Instalar dependencias
npm test             → Probar conexiones
npm run export       → Exportar datos de WooCommerce
npm run dry-run      → Migración en modo prueba
npm start            → Ejecutar migración real
npm run migrate      → Alias de npm start

====================================================
  FLUJO DE TRABAJO RECOMENDADO
====================================================

1. npm install
2. Copiar config.example.env → .env
3. Configurar credenciales en .env
4. npm test
5. npm run export
6. npm run dry-run
7. Revisar logs
8. Editar .env → DRY_RUN=false
9. npm start
